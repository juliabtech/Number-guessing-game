Number Guessing Game

A simple number guessing game using Java to build it. The player has 5 attemps to guess a random number between 1-12.

- Random number generation.
- Five attempts.
- Option to play again.
- Hints.
- Displays the correct answer if the player loses.

- Java methods.
- Loops (while and for).
- Conditional Statements.
- Logical operators.
- User input.
